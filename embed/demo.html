QBasic programs on any web page

Each example below runs a QBasic program in a sandboxed frame that shows only its screen. The HTML under each one is everything it takes. The full guide is doc/embedding.md.

  1. The program written in the page
  2. A .bas file
  3. A package (.zip) whose files are kept
  4. Driving it from JavaScript
  5. A plain <iframe>, with no script
  6. A shareable link

1. The program written in the page

Put the program inside <qb-program>, in a <script type="text/x-qbasic"> so that < and & need no escaping. Without autostart the reader presses Run first. Click the screen to type into it.

2. A .bas file

src names a file to fetch. A relative URL is relative to this page; a file on another site needs that site to allow it (CORS). The screen is scaled to fit the box.

3. A package whose files are kept

A .zip holds the program and its files. Its qbjs.json names the program to run, a title and the COMMAND$ arguments. With persist, the files the program writes are kept in this browser under that key and given back next time: run it, reload the page, and run it again. (The zip holds visits.bas, banner.txt and qbjs.json.)

4. Driving it from JavaScript

The element has methods (load, run, stop, readFile, writeFile, fullscreen) and fires events (qb-start, qb-end, qb-error, qb-message for _ECHO, qb-title, qb-resize...). Edit the program and load it; try a mistake to see the error event.

    const lab = document.getElementById('lab');
lab.addEventListener('qb-message', (e) => console.log(e.detail.message));
lab.addEventListener('qb-end', (e) => console.log('ended:', e.detail.reason));
await lab.load({ source: text, name: 'circles.bas' });
lab.run();

    5. A plain <iframe>, with no script

    Where a page can't run scripts (some blogs, wikis and forums), point an <iframe> at embed/player.html and give the settings in its URL. Here a relative src is relative to the engine's folder (where index.html is), not this page. Keep the sandbox attribute: it is what keeps the program away from the page.

    6. A shareable link

    A short program fits in the link itself: #code= holds the program, compressed and encoded. Opened on its own, the link fills the window; it also works as an <iframe> src. Nothing is stored on a server.
