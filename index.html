        Editor
        

          
        

        
Writes keywords such as PRINT and LEFT$ in capitals as you type, as the QB64 IDE does. Strings, comments, DATA and $IF JAVASCRIPT blocks are left alone.

      

      

        About
        
A browser IDE for writing and running QB64 / QBasic programs. Programs are compiled to JavaScript by
          QBJS and run entirely in this page.

        
QBJS supports most of QBasic and a large part of QB64, but not all of it. Check the
          supported keywords and
          language notes.
          Programs that call Windows or C libraries won't run.
